# Customer_behavior_analysis
# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across various product categories. The objective is to identify spending patterns, customer segments, product preferences, and subscription behavior to support business decision-making.

## Dataset

The dataset contains 3,900 records and 18 columns.

### Features Included

* Age
* Gender
* Location
* Subscription Status
* Item Purchased
* Category
* Purchase Amount
* Season
* Size
* Color
* Discount Applied
* Previous Purchases
* Frequency of Purchases
* Review Rating
* Shipping Type

## Tools Used

* Python (Pandas)
* PostgreSQL
* SQL
* Power BI
* Gamma AI
* Microsoft Word

## Project Steps

### 1. Data Preparation & Cleaning

* Loaded dataset using Pandas.
* Checked dataset structure and summary statistics.
* Handled missing values in Review Rating.
* Renamed columns using snake_case format.
* Created age_group feature.
* Removed redundant columns.
* Loaded cleaned data into PostgreSQL database.

## How to Run

1. Load the dataset in Python.
2. Perform data cleaning and EDA.
3. Import cleaned data into PostgreSQL.
4. Execute SQL queries for analysis.
5. Connect Power BI to the database.
6. Build dashboard visualizations.
7. Prepare the final report and presentation using Gamma AI.
